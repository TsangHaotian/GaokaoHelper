获取 GLM-4-Flash API Key 完全免费

官网：bigmodel.cn

虽然智谱有付费模型，但本工具调用的 GLM-4-Flash 为完全免费模型，因此不消耗任何费用。

1 打开智谱开放平台

访问 bigmodel.cn，点击「登录注册」。

2 注册 / 登录账号

使用手机号注册或登录。

3 登录成功

登录成功后点击「控制台」。

4 进入 API Key 管理

在左侧菜单栏找到「API Key」，点击进入。

5 创建 API Key

点击「创建 API Key」，名称随便写。

6 填写名称

输入名称，点击确认创建。

7 填入 GaokaoAI

创建成功后，点击 Key 后面的「复制」按钮，粘贴到 GaokaoAI 设置中的 API Key 输入框，点击「保存」即可。
