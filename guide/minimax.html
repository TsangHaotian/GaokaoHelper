获取 MiniMax API Key

官网：platform.minimaxi.com

1 打开 MiniMax 开放平台

访问 platform.minimaxi.com，找到登录选项（手机端可能需要仔细寻找）。

2 登录账号

点击「登录」，使用手机号或邮箱登录。

3 登录成功

登录后会跳回主页面。

4 进入用户菜单

点击右上角用户头像。

5 进入 API Key 管理

到达 API Key 管理界面。

6 获取 API Key

在菜单中点击「获取你的 Key」，进入 API Key 管理页面。

7 创建 API Key

点击「创建新的 API Key」，名称随便填。

8 填入 GaokaoAI

复制生成的 API Key，粘贴到 GaokaoAI 设置中的 API Key 输入框，点击「保存」即可。
