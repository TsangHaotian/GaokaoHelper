获取 Moonshot API Key

官网：platform.moonshot.cn

1 打开 Moonshot 开放平台

访问 platform.moonshot.cn，注册并登录账号。

2 注册账号

建议直接用手机号注册，首次注册送15元免费额度。

3 进入 API Key 管理

登录后，点击左侧菜单的「API Key 管理」。

4 新建 API Key

点击「新建 API Key」，名称和项目随便填写。

5 确认创建

点击确认，完成创建。

6 填入 GaokaoAI

复制 API Key，粘贴到 GaokaoAI 设置中的 API Key 输入框，点击「保存」即可。
