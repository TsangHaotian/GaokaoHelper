获取 DeepSeek API Key

官网：platform.deepseek.com

1 打开 DeepSeek 开放平台

访问 platform.deepseek.com，注册并登录账号。

2 注册 / 登录账号

使用手机号或邮箱注册账号，若已有账号直接登录。

3 进入 API Key 管理

登录后，在左侧菜单栏找到「API Keys」，点击进入。

4 创建 API Key

点击「创建 API Key」按钮，输入名称（任意填写），创建后复制 Key 并保存。

注意：关闭弹窗后 Key 将不再完整显示，请务必先复制。

5 填入 GaokaoAI

将复制的 Key 粘贴到 GaokaoAI 设置中的 API Key 输入框，点击「保存」即可。
